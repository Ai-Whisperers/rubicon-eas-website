## Templates de contenido

### LinkedIn — Artículo largo
```
# [Título con keyword]

[Hook: pregunta o afirmación fuerte]
- 1-2 líneas que enganchan

[Contexto: el problema o la situación]
- 3-5 párrafos cortos

[Insight: lo que la mayoría no sabe]
- 1-2 párrafos de análisis

[Solución: qué hacer]
- Lista numerada de 3-5 puntos

[Cierre: pregunta abierta para engagement]

#civilpenal #paraguay #abogadoasuncion
```

### LinkedIn — Análisis corto (200-400 palabras)
```
[Sentencia / tema] — [1 línea resumen]

Contexto (3 líneas):
[qué pasó, cuándo, dónde]

Por qué importa (2 líneas):
[relevancia para clientes PY]

Lo que cambia en la práctica (3 líneas):
[implicación concreta]

[Pregunta para engagement]

#paraguay #derecho
```

### LinkedIn — Visual (foto + texto)
```
[Foto: oficina, evento, firma, etc.]

[1 frase de contexto]

[2 frases de insight]

#paraguay #abogadoasuncion
```

### Blog — Artículo SEO (800-1500 palabras)
```
# [Keyword en H1]

[Meta description 150 chars]

[Introducción: 2-3 párrafos con keyword en primer párrafo]

## [Subtítulo 1 con keyword]
[3-5 párrafos]

## [Subtítulo 2]
[3-5 párrafos]

## [Subtítulo 3 con keyword]
[3-5 párrafos]

## Conclusión
[Resumen + CTA "Consultar"]

## Preguntas frecuentes
### [Pregunta 1]
[Respuesta 200 palabras]

### [Pregunta 2]
[Respuesta 200 palabras]
```

### GBP post
```
[Foto 1080x1080px o 1200x900px]

Texto (500-1500 caracteres):
- Empezar con hook
- Dar contexto
- Ofrecer valor (info, no venta)
- Cerrar con CTA
```

## Producción semanal típica

| Día | Tiempo | Actividad |
|---|---|---|
| Lunes | 90 min | Escribir 1 LinkedIn largo (800-1500 palabras) |
| Martes | 30 min | Tomar fotos (oficina, eventos, casos anónimos) |
| Miércoles | 30 min | Escribir 1 LinkedIn corto (200-400 palabras) |
| Jueves | 60 min | Escribir 1 artículo blog SEO |
| Viernes | 30 min | Publicar 1 LinkedIn visual + 1 GBP post |
| Sábado | 30 min | Responder comentarios, programar posts |
| **TOTAL** | **~5h** | **~4-5 piezas de contenido** |

Para una persona con trabajo full-time, **5 horas/semana es manejable**. Si la carga es mucha, contratar a un editor de contenido (Gs. 200-500k/post) o usar AI Whisperers (Gs. 0, ya incluido en Plan B).
