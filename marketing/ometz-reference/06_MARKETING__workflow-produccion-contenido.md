## 🎯 OBJETIVO

Definir **quién hace qué, cuándo, con qué herramientas y cómo aprueba** cada pieza de contenido de Ometz Dental. Para que la producción no dependa del humor de Gaby o de la disponibilidad de Kiki — sea **sistema replicable**.

## 📅 RITUALES SEMANALES (sistema operativo)

### Lunes 9:00 — REVISIÓN SEMANAL (30 min)
**Asistentes:** Gaby + Kiki (+ CM si hay)
**Objetivo:** revisar la semana anterior + aprobar la siguiente

**Agenda:**
1. **Métricas semana anterior** (5 min)
   - Posts publicados vs. planificados
   - Engagement rate promedio
   - Mensajes WhatsApp recibidos
   - Reseñas nuevas
   - Visitas al sitio web
2. **Revisión del contenido** (10 min)
   - ¿Algún post performó notablemente mejor/peor? ¿Por qué?
   - ¿Algún comentario que requiere respuesta?
   - ¿Algún mensaje de WA que requiera seguimiento?
3. **Aprobación contenido semana siguiente** (10 min)
   - Kiki muestra los 3 visuales diseñados
   - Gaby aprueba o sugiere cambios
   - Si hay caso clínico sensible, validar consentimiento
4. **Tareas administrativas** (5 min)
   - Reseñas para responder
   - Mensajes WA para follow-up
   - Actualización de GBP (1 post)

### Domingo 21:00 — PROGRAMACIÓN (45 min)
**Asistente:** CM (o Kiki)
**Objetivo:** dejar toda la semana siguiente lista en Meta Business Suite

**Tareas:**
1. Abrir `calendario-marketing-2026-completo.md`
2. Identificar los 3 slots de la semana siguiente
3. Para cada slot:
   - Buscar copy en `52-posts-pre-armados-anuales.md`
   - Personalizar placeholders si hay (ej. números del balance)
   - Adjuntar visual correspondiente desde Drive
   - Programar en Meta Business Suite con horario óptimo
4. Verificar que no falten assets
5. Confirmar y salir

### Mensual (primer lunes del mes) — PLANIFICACIÓN MENSUAL (1h)
**Asistentes:** Kiki + CM
**Objetivo:** dejar el mes entero programado

**Tareas:**
1. Revisar el mes en el calendario
2. Identificar fechas especiales (ver `calendario-feriados-paraguay-2026.md`)
3. Adaptar copy de la biblioteca si hay evento especial
4. Aprobar visuales de cada post del mes
5. Coordinar con Gaby si hay sesión de fotos o evento
6. Programar en bloque (no por semana)

### Trimestral — REVISIÓN ESTRATÉGICA (2h)
**Asistentes:** Iván + Kiki + Erebus (si aplica) + Gaby
**Objetivo:** evaluar el sistema completo + iterar

**Tareas:**
1. Métricas trimestrales (alcance, engagement, leads, conversión, ROI)
2. ¿Qué funcionó? ¿Qué no?
3. Actualizar calendario para el trimestre siguiente
4. Ajustar biblioteca de posts según aprendizajes
5. Evaluar necesidad de community manager externo
6. Decidir sobre Meta Ads (empezar / escalar / pausar)

## ✅ WORKFLOW POR PIEZA DE CONTENIDO

### Para un POST de Facebook (caso más común)

```
1. CM identifica el slot del calendario
   → revisa `calendario-marketing-2026.md`
   → busca el copy en `52-posts-pre-armados.md`

2. CM elige el template en Canva
   → abre `01_BRAND/...` para tener paleta + logo
   → duplica el template correspondiente
   → customiza texto + visual
   → exporta PNG 1080×1080

3. CM sube el visual a Drive
   → carpeta del mes correspondiente

4. CM redacta el copy final
   → adapta del pre-armado (placeholders, números)
   → valida contra compliance ético
   → valida que respete el ADN

5. CM programa en Meta Business Suite
   → día + hora del slot
   → adjunta visual
   → copy completo
   → hashtags al final

6. Kiki revisa el lunes 9:00
   → si hay algo sensible, escala a Gaby
   → si está OK, queda programado

7. Post se publica automáticamente

8. CM responde comentarios en <4 horas

9. CM mide resultados al lunes siguiente
```

### Para un CASO CLÍNICO (antes/después)

```
1. Gaby realiza el caso y toma fotos (en Ometz o derivando)

2. Paciente firma consentimiento informado
   → usar plantilla en `09_TEMPLATES/`
   → guardar consentimiento firmado en Drive/casos/

3. Gaby envía fotos + consentimiento a Kiki/CM

4. Kiki/CM edita fotos (recortar cara si es necesario)
   → usa plantilla "caso clínico" en Canva
   → antes | después | descripción educativa
   → nombre del paciente NUNCA visible

5. Gaby aprueba el post (caso sensible)

6. CM publica + etiqueta en stories (opcional)

7. CM guarda captura de la publicación + métricas
```

### Para un ARTÍCULO DE BLOG (SEO)

```
1. Erebus / Copy-Bot escribe el artículo
   → usar `06_MARKETING/blog-posts-seo/` como template
   → 1500-2000 palabras
   → SEO on-page: H1 con keyword, meta description, alt text en imágenes

2. Kiki revisa tono + compliance

3. Dev (Iván) sube al sitio web
   → formato markdown → HTML estático
   → agregar a sitemap.xml
   → Open Graph + Twitter cards

4. CM publica link en Facebook + GBP

5. Erebus mide ranking en Google Search Console
   → ajustar si es necesario
```

## 🚨 PROTOCOLO DE CRISIS

### Si un post genera comentarios negativos masivos:

1. **No responder en caliente.** Esperar 1-2 horas.
2. **Kiki escala a Gaby** si el tema es clínico.
3. **Si es sobre pricing**: derivar a mensaje privado.
4. **Si es sobre resultado clínico**: invitar a consulta (sin entrar en debate público).
5. **Si es mentira o difamación**: considerar eliminación + denuncia.
6. **Documentar todo**: captura, hora, contexto.

(Ver `05_OPERATIONS/guia-crisis-reputacional.md` para el protocolo completo.)

### Si se cae el sitio web:

1. **Avisar a Iván inmediatamente**.
2. **Publicar story de IG/FB** con explicación breve.
3. **WhatsApp Business con mensaje alternativo**: "Sitio en mantenimiento, escribime directo".
4. **Dev trabaja en fix**, status update cada 30 min a Kiki.
5. **Post-mortem** en lunes siguiente.
