## Lessons / patterns

1. **Token-handling:** never put CF tokens in repo code. Use env-var references + scrub before commit.
2. **Worker syntax check:** `node --check` before deploy to catch syntax errors.
3. **CF cache lag:** always use cache-buster query when testing deploys.
4. **Sitemap + robots.txt:** cheap SEO wins, every site needs them.
5. **Schema.org:** structured data boosts rich snippets in Google.
6. **Lead intake standardization:** same schema as Ometz Dental → forkable.
7. **CI scripts run locally:** faster dev cycle than waiting for GitHub Actions.
